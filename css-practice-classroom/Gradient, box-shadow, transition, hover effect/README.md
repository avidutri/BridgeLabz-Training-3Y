# Gradient, Box-Shadow, Transition, and Hover Effect

## Project Overview
This project demonstrates CSS styling techniques including:
- **Gradients** - Linear and radial gradients for background styling
- **Box-Shadow** - Multiple shadow effects for depth and visual appeal
- **Transitions** - Smooth animations between CSS property changes
- **Hover Effects** - Interactive styling on user interaction

## Files
- `index.html` - HTML structure for the project
- `style.css` - CSS styling with gradients, shadows, transitions, and hover effects

## Features
- Responsive design with gradient backgrounds
- Box shadow effects for card/element depth
- Smooth transitions on hover interactions
- Interactive hover effects for enhanced UX

## Usage
Open `index.html` in a web browser to view the gradient, box-shadow, transition, and hover effect demonstrations.
