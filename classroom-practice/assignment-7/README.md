# Assignment 7 - CSS Foundations and Visual Effects

This assignment contains ten standalone HTML and CSS exercises. Each question uses semantic HTML5, pure CSS, Flexbox or Grid where appropriate, and responsive styling without JavaScript or external frameworks.

## Questions

| Question | Folder | Focus |
| --- | --- | --- |
| Q1 | `q01-borders-padding/` | Border styles, padding, rounded corners, hover transition |
| Q2 | `q02-height-width/` | CSS units, min/max sizing, overflow, Flexbox centering |
| Q3 | `q03-gradients/` | Linear and radial gradients, fixed header/footer, fixed attachment |
| Q4 | `q04-shadows/` | Box shadows, text shadows, hover lift, transitions |
| Q5 | `q05-advanced-selectors/` | Attribute selectors, pseudo-classes, pseudo-elements, combinators |
| Q6 | `q06-transforms/` | Rotate, scale, translate, and skew transformations |
| Q7 | `q07-typography/` | Font families, weights, spacing, alignment, text pseudo-elements |
| Q8 | `q08-box-model/` | Content, padding, border, margin, and box sizing |
| Q9 | `q09-focus-form/` | Form outlines, focus states, spacing, radius, and shadows |
| Q10 | `q10-navigation/` | Responsive navigation, active state, hover transitions, footer |

## How to view

Open any question folder and launch its `index.html` file in a browser. Resize the browser window and hover or focus the interactive elements to see the CSS behavior.
