# HTML Resume

## Overview

This project is a personal resume created using **only HTML**. It demonstrates the use of basic HTML elements to design a structured and readable resume without using CSS or JavaScript. The project is suitable for beginners learning HTML fundamentals and fulfills assignments requiring pure HTML.

---

## Features

- Built using only HTML5
- No CSS or JavaScript used
- Simple and easy-to-read layout
- Organized sections for personal and academic information
- Uses tables, lists, headings, and paragraphs
- Compatible with all modern web browsers

---

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click **resume.html**, or open it using any web browser.

No installation or additional software is required.
