**Smart Examination Portal**

A simple front-end project that demonstrates a basic online examination interface for students and instructors.

**Description:** A lightweight HTML/CSS/JavaScript application for creating and taking quizzes, tracking scores, and navigating questions in a simulated exam environment.

**Features:**
- Multiple-choice question layout
- Navigation between questions
- Immediate score calculation
- Responsive layout for desktop and mobile

**How to run:**
- Open `index.html` in your browser (double-click or use Live Server extension).

**Files:**
- `index.html` — main exam UI
- `styles.css` — styling (if present)
- `script.js` — client-side behavior (if present)

**Notes:**
- This is a front-end prototype; no backend or persistent storage is included.
- To add questions, edit the HTML or the JavaScript question array (if implemented).
