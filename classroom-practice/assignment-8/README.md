# Assignment 8 - CSS Pseudo-classes, Effects, and Layout Practice

This assignment contains ten CSS-focused exercises covering pseudo-classes, transitions, selectors, tooltips, animations, layout patterns, UI components, and responsive design.

## Questions

1. Pseudo-classes demo
2. Tooltip demo
3. Image showcase
4. Selector practice
5. Button collection
6. Animation demo
7. UI components card
8. Box-sizing comparison
9. Combined effects demo
10. Mini user interface layout

## How to view

Open any question folder and run its `index.html` file in a browser to see the effect.
