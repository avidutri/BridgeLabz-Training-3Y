# Assignment 9 - Responsive CSS Practice

This assignment includes ten responsive web design exercises using semantic HTML5, CSS Grid, Flexbox, media queries, filters, and animations.

## Questions

1. Responsive Image Filter Gallery
2. Responsive Web Design Layout
3. Responsive Cards with Media Queries
4. Responsive Typography
5. Filter Cards with Animation
6. Responsive CSS Cheat Sheet
7. Combined Responsive Web Demo
8. Filter Comparison Layout
9. Responsive Design Principles Summary
10. Responsive Dashboard Summary

## How to view

Open any question folder and launch its `index.html` file in a browser.
