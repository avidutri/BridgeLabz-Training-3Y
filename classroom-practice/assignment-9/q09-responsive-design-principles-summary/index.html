Responsive Design Principles

Fluid Layouts

Layouts use percentages and flexible units so content adapts smoothly.

.container { width: 90%; }

Flexible Media

Images and videos are scaled proportionally to fit varying screen sizes.

img { max-width: 100%; }

Breakpoints

Media queries apply different rules at key viewport widths.

@media (max-width: 600px) { ... }
