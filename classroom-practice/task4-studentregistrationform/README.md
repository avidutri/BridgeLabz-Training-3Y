**Student Registration Form**

A simple front-end form that collects student details (name, roll, class, email, contact, and other fields) and demonstrates basic form layout and validation using HTML and optional JavaScript.

**Description:**
This project contains a responsive registration form suitable for learning HTML form elements, client-side validation, and basic styling.

**How to use:**
- Open `forms.html` in a browser (double-click or use Live Server).
- Fill in the fields and submit to test client-side behavior (if JavaScript validation is implemented).

**Files:**
- `forms.html` — the registration form UI
- `README.md` — this file

**Notes:**
- No backend or persistent storage is included.
- To save submissions, connect the form to a server endpoint or use a service like Formspree or Google Sheets.
