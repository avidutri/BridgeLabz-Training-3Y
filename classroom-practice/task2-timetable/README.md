# College Timetable using HTML

## Overview

This project is a simple **College Class Timetable** created using **only HTML5**. It demonstrates how to organize and display a weekly class schedule in a tabular format without using CSS or JavaScript. The timetable is designed for a **3rd Year B.Tech Computer Science Engineering** student and showcases the use of basic HTML elements.

---

## Features

* Developed using **HTML5 only**
* No CSS or JavaScript
* Clean and easy-to-read table layout
* Weekly timetable from Monday to Saturday
* Includes lecture timings, lunch break, labs, and project sessions
* Beginner-friendly HTML project

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click **timetable.html** or open it in any modern web browser.

No installation or additional software is required.
