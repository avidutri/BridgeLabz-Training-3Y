Responsive CSS Cheat Sheet

Filters

Used to change the appearance of images.

filter: grayscale(100%);

Media Queries

Used to apply CSS according to screen size.

@media (max-width: 700px)

Responsive Design

Design that adapts to different devices.

width: 100%;

Typography

Responsive text can use relative units.

font-size: clamp(1rem, 2vw, 2rem);
