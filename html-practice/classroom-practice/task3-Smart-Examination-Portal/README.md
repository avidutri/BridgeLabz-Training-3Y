# Smart Examination Portal

A simple Smart Examination Portal webpage created using only HTML.

## Project Description

This project is a basic examination portal webpage designed using HTML.
It contains a navigation menu, welcome section, examination information,
team section, images and footer.

## Features

- Smart Examination Portal homepage
- Navigation links
- Moving welcome message
- Examination information
- Team section
- Images
- Footer section

## Technologies Used

- HTML5

## Restrictions

This project is created using **HTML only**.

- No CSS
- No JavaScript
